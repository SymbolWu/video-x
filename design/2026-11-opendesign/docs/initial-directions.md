# video-x 视觉探索约束

这是独立设计原型，数据来源为 reference/sample-data.json；正式产品当前操作见两张 before 截图。

共同基础：系统字体栈 -apple-system, BlinkMacSystemFont, Inter, PingFang SC, Microsoft YaHei, sans-serif；中文阅读优先。4/8/12/16/24px 间距体系，正文14至16px。常规文本对比度至少4.5:1，触控区至少44px。信息、操作、个人状态分别清楚，避免只靠颜色。

A「深色放映室」：背景 #101115，表面 #191b22，文字 #ececf1，次要文字 #adb2bd，强调 #ff8da8。顶部导航，舒展海报网格，图片和片名是主要信息，少量描边和低调层级。

B「私人影档」：暖白背景 #f5f3ee，表面 #fffdfa，墨黑文字 #242322，次要文字 #68625c，强调 #884352。纤细侧栏和清楚的目录层级；精确对齐与有档案感的排版；主体仍是海报网格。

所有内容为虚构设计样本。保留无图记录、长标题、喜欢、评分、已看状态。筛选和搜索结果可清除，详情返回恢复列表上下文和焦点。不要加入宣传横幅、会员促销或虚构统计。两个方向都检查1440×900和390×844。
