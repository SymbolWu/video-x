# 当前设计决定

2026-11-27。适用当前观看端 HTML 原型；历史简报只用于理解演进。

## 品牌与视觉

- 主色使用 `packages/design-tokens/tokens.css` 的 `--accent: #ff6f91`，透明与悬浮状态由此派生。原型提取快照位于 `prototype/theme-tokens.css`。
- Logo 为 V/X 与播放负形的矢量标记，通过 CSS mask 跟随主色。图像生成用于方向探索，最终 SVG 为清晰的矢量实现；原图与简报保存在 `references/brand/`。
- 深色导航和必要浮层采用克制的玻璃效果。海报、人像和正文保持清晰。喜欢按钮具有透明镜片、背景模糊、细白边与内高光。
- 原生滚动条使用细圆角滑块、透明轨道和悬停/拖动反馈，桌面预留稳定滚动槽。

## 片库与独立作品页

- 影片、演员、系列采用线型页签与可移动指示线；分类采用胶囊态，类型与筛选的层级可区分。
- 工具区采用轻量布局，排序、筛选和视图切换统一排布。演员与系列详情使用自己的资料区和固定成员范围，结果数量放在作品标题旁。
- 页签和列表有短暂过渡，排序为锚定菜单，筛选有进退和已启用状态。系统减少动画时直接完成状态变化。
- 从目录下钻到演员/系列、影片后逐层返回，恢复每一层的条件、排序、滚动与焦点；清空搜索不丢失固定实体范围。

## 系列封面与长页

系列封面按用户提供的书刊叠放参考重排：同方向、等步幅错位，第一位成员为前景主封面，另外两位成员在左下方依次露出。目录与系列详情共享同一套封面。每层来自不同成员；单部只显示一张海报，不复制图片伪造多部。

新增「007」25 部不同作品作为长页样本。系列保存顺序为新作在前，浏览排序不修改成员保存顺序。资料与海报来源见 `prototype/references/sources.json`，个人状态为合成，新增影片未关联真实文件。整个原型有 45 部影片、6 位演员和 7 个系列。

## 影片详情

播放与版本选择按钮实际外框均为 48px。版本使用就地单选下拉菜单，点选后更新并收起，不自动播放；支持键盘、Esc、点外部关闭和窄屏定位。资料缺失时如实显示，不生成虚构的播放版本。
