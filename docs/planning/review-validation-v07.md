# 录入交互 V0.7 验证记录

2026-11-17 · PRD 1.1 / 原型 V0.7 / 数据库候选 v0.5

本轮针对“列表看不出抓取了什么、分集创建路径不清楚”重新检查旧代码，并更新录入工作区与产品需求。生产 Web、后端、Android、运行库和磁盘媒体未修改。

## 1 代码依据与变化

旧版 `DraftTable.tsx` 直接展示封面、演员、分类、系列、发行日期与文件，并提供选择、缺失筛选和预览；`EpisodeGroupModal` 和 `episode-group-utils` 使用已选视频、指定资料来源生成无文件容器。这些能力对应本轮结果总览、同页建立分集组和父子列表。详见[交互规则](ingest-interaction-v07.md)。

完整编辑器保留，作为按需修改入口。获取结果、常用项缺失和人工确认分别显示；可多选后汇总核对，明确确认后才能手动发布。

## 2 已执行的检查

| 范围 | 结果 |
| --- | --- |
| 自动交互 | `catalog.test.cjs` 与 `schema-ui.test.cjs` 共 52 项通过；新增覆盖列表实际值/缺项、未确认选择、容器资料来源与集顺序、取消、整组核对/发布、结构与版本变更阻断、解除分组保留文件、分类使确认失效、批量操作范围与重新获取保留人工值 |
| 浏览器创建 | 勾选虚构“海岸来信 · 上部/下部”，编辑容器名、查看资料来源与文件顺序，创建后原列表展开容器和各集 |
| 浏览器核对 | 搜索后勾选容器自动选中两集；汇总中容器在前、分集有序；下部缺封面和简介有明确提示，“确认这些资料”可用；取消保留草稿 |
| 桌面布局 | 正常窗口查看结果总览、创建容器和核对面板；另检查 1280×720，结果表与容器同宽，无页面或表格横向溢出，弹窗主操作可见 |
| 数据依据 | 新的列表缺项由草稿计算；获取、确认、父子关系和版本文件均使用 v0.5 已有设计字段，无新增 DDL |
| 演示边界 | 所有操作仅为静态原型和虚构样本；没有真实抓取、探测、服务端事务或生产发布 |
