# 现有系统能力基线与改版去向

2026-11-17。按代码中的页面、操作、请求契约和保存逻辑建立基线。**保留功能意图不等于照搬旧缺陷；界面存在不等于后端已正确实现。** 本表覆盖本轮审阅的主要用户能力，不宣称穷尽每个内部函数。原型未覆盖的能力必须显式登记，不能据此从首版需求中删除。

## 5 评审与落地规则

PRD、原型和数据库通过上述编号追踪。只有用户明确取消的 alias、待清理及已确认后置项直接退出首版；文件整理等产品取舍应单列。其余“原型待补”代表设计交付缺口，不代表功能取消。

本轮优先补齐完整草稿编辑、来源逐字段核对、文件/版本操作、细分筛选、演员资料补全、收藏夹移动和客户端设置。真实图片上传、服务器目录、抓取、文件探测、任务恢复、跨设备播放仍由正式工程验收，原型只使用虚构本地样本。
