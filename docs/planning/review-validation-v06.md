## 未完成的实现与原型边界

- 真实文件选择、服务端持久化、真实上传/探测/抓取、播放 seek、并发发布和任务恢复未实现。
- HTML 中的多来源候选只展示简化样本；完整的来源关系差异、标签/片商就地新建、全部批量操作、发布后变更摘要仍需补充界面。
- 原型的跨页多选、服务端分页、真实数据下的父子聚合、文件内容变化后的断点裁决仍需实现和验收。
- 文件移动、无文件正式资料、探测失败放行等本次建议集中于 PRD 第 14 节，未视作用户已经确认。
- 数据库包含后置候选字段；正式 migration 应从已评审范围生成，不能直接把候选全集当成首版已批准结构。

这些未完成项保留在产品需求和核对表中，不能因为原型暂未演示就从业务范围删去。
