# 界面与交互规范

## 每个页面先回答四个问题

用户从哪里来，这一屏要判断什么，最常用的动作是什么，完成或取消后到哪里。设计覆盖默认、有内容、无数据、无匹配、加载失败和可重试状态；只对该流程实际存在的状态出图或做验收。已有页面调整可直接在开发版验证。新增页面结构或改变多步流程时，先用代表性内容走通一个可点的样例，再推广到同类入口。

## 布局与视觉基线

| 场景 | 实施与验收 |
| --- | --- |
| 管理端框架 | 桌面沿用 184 px 侧栏、46 px 顶栏和固定内容起线。选中项用短竖线、字重和 `aria-current` 标记，鼠标悬浮与键盘焦点分别可辨。切换路由、打开下拉或弹窗时核对标题、工具栏和首列的横坐标。 |
| 密度与对齐 | 以 4、8、12、16、24 px 组织间距。同一工具栏的输入框、下拉和按钮采用同档高度，管理端常用 32–36 px。页面标题、工具栏、卡片网格共用左右边线。正文和操作文字须能直接读清，次要信息用字重、位置和间距区分。长标题允许截断并提供完整阅读入口。 |
| 色彩和控件 | 先使用现有主题的背景、文字、边框、强调与状态色，新增可复用语义值放回主题。常规可操作文本与背景的项目对比度目标为 4.5∶1。分别验默认、悬浮、按下、键盘焦点、禁用与处理中。状态用文字或图标辅助颜色。触控端保留足够命中区，Android 常用按钮至少 48 dp。 |
| 列表与卡片 | 管理片库默认横图（3∶2），可切海报（2∶3）和表格。横图与海报优先使用对应图片，缺图或加载失败时尝试另一张，完整显示原图并保持同排对齐。原图比例不同留下的空隙，用同一图片的低亮度模糊背景填补。演员和系列卡片进入完整详情与作品网格。系列封面铺满卡片，标题落在底部渐变的可读区域。录入队列保留封面、文件、缺项、状态及按任务分组的操作。无封面时保持卡片对齐，详情随内容收紧。 |
| 表单与弹窗 | 字段标签、输入与校验共用一条对齐线。小枚举用共享选择框；演员、系列、片商等大集合用带搜索、分类、分页和已选反馈的选择面板。支持批选的面板须保留跨页选择。影片编辑中的系列和标签默认使用当前主分类，切换分类时保留本次已选。标签按资料维护中的属性组展示。目标目录树显示路径与可得的文件计数，数量未知时明确区分零。 |
| 观看与播放 | 详情页按信息、播放动作、个人状态和关联作品排布。播放进入独立播放器，多版本有清晰名称或分辨率。退出回到对应作品；版本切换要核实实际播放文件和进度。窄屏验证长标题、大字体和系统返回。 |

管理端「资料维护」顺序为演员、系列、收藏夹、分类、标签、片商。「运行」保留后台任务与系统状态。抓取结果与字段核对归录入，插件状态归系统状态。演员资料补全与归档沿用首版隐藏决定。新增导航项先说明对应的独立任务。

## 把流程验到终点

- **编辑。** 草稿及已发布影片共用编辑框架。每次保存影片资料校验完整发行日期。旧资料可以打开并提示补全。封面与剧照分别维护，来源核对只在录入出现，容器详情才提供分集维护。保存成功后重新打开可见，失败保留输入，取消返回原上下文。
- **选择与批量操作。** 从系统状态选择下载目录，回录入从该目录勾选样片，设目标、核对、手动发布。提交前让用户看清范围和目标。已处理、失败和待处理项分别可辨；同名、离线或资料缺失说明原因与修正入口。
- **浏览与弹层。** 返回列表恢复筛选、页码、滚动位置及触发控件焦点。Esc 或 Android 系统返回每次关闭最上层。空搜索可清除条件，读取失败可原位重试。弹窗具备可访问名称、初始焦点和可达的关闭操作，键盘可走完整条路径。
- **交付取证。** 桌面以 1440 × 900 为设计对照，再在较窄窗口验证换行和溢出；观看端至少复查 390 × 844 的手机布局。用长片名、无图、零结果和双版本等样本验证被改动的场景。提交实际界面和关键操作结果，注明设备、视口、数据、实测范围。涉及播放须记录实际解码尺寸或可辨识的版本画面。

当前实现参照 [管理端外壳](../../apps/admin/src/app/admin-shell.css)、[公共视觉变量](../../packages/design-tokens/tokens.css)、[观看端片库](../../apps/web/src/features/library) 与 [Android 共享控件](../../apps/android/app/src/main/java/com/wuxinbo/videox/ui/components)。

观看端的回归样本应同时包含有图和无图的续播记录，核对同一行卡片的对齐、长片名、进度和直接续播。演员与系列入口用自己的资料页承载馆藏作品；返回时恢复原入口。桌面页签分别验收鼠标悬浮、当前项与键盘焦点，手机从发现页发起搜索后应立即看到片库结果。
